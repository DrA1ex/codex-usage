How to read these numbers

In capacity mode, each eligible window is one observation. The average is the selected metric summed across windows, divided by the number of windows. Tokens are neither price-weighted nor extrapolated to 100%.

A 98% threshold includes exhausted and nearly exhausted windows. Set 100% for a strict sample. A 98–99% snapshot alone does not prove exhaustion.

Cached tokens are included in input; reasoning tokens are included in output. Total tokens = input + output. Model responses count internal steps, rather than user messages.

The dominant model is determined by its share of ordinary tokens. If no model meets the threshold, the window is classified as Mixed models. The window table shows the breakdown.

Voice, images and other features sharing the budget can reduce the tokens available to working models. These numbers describe observed usage; the server's absolute quota settings are absent from the data.

New models and numeric usage fields are discovered automatically. Model names do not determine token prices or weights.
